4. ARCHITECTURAL HIGHLIGHTS
-------------------------------------------------------------------------------
- Base Model: TinyLlama/TinyLlama-1.1B-Chat-v1.0
- Prompting Format: ChatML (<|system|>, <|user|>, <|assistant|>)
- Context Bounding: Input strictly bounded to GenerationContext with maximum
  6 recent conversation messages. No database dumps, passwords, or PII exposed.
- System Guardrails: Non-clinical framing; explicit prohibitions against diagnosis,
  medical claims, and medication recommendations.
- Validation: Deterministic regex validator checking for empty output, prompt
  leakage, diagnostic claims, medication recommendations, medical directives,
  and unsafe crisis content.
- Urgent Safety Bypass: Bypasses SLM generation entirely when safety level is
  'urgent' or policy is 'escalate_urgent', returning deterministic crisis support.
- Model Fallback Policy:
  Production SLM inference NEVER silently falls back to mock generation.
  If model loading fails when MOCK_SLM=false, an HTTP 503 SERVICE UNAVAILABLE
  error is raised. Mock mode is strictly governed by the explicit MOCK_SLM configuration.
- Fine-Tuning Separation:
  The training pipeline (LoRA via PEFT / TRL SFTTrainer) is completely isolated
  in backend/training/ and never executed by the FastAPI server runtime.
